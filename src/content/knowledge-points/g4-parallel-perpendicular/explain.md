# 平行与垂直

## 两条直线的关系

在同一平面内，两条直线有几种关系？

1. **相交**——两条直线碰到一起，有一个交点
2. **平行**——两条直线永不相交
3. **垂直**——相交且成 90° 角（是相交的特殊情况）

## 什么是平行？

**平行**是指两条直线在同一平面内**永不相交**。

```
  ───────────  直线 a
  ───────────  直线 b
```

记作：a ∥ b（读作 a 平行于 b）

平行的特点：
- 两条平行线之间的距离**处处相等**
- 不管延伸多长，都**不会碰到一起**

> 💡 想想铁轨：两条铁轨就是平行的，永远一样宽，不会碰到一起。

## 什么是垂直？

**垂直**是指两条直线相交成 **90° 角**（直角）。

```
      |
      |
  ────●────
      |
```

记作：a ⊥ b（读作 a 垂直于 b）

垂直的特点：
- 两条直线相交且夹角是 90°
- 交点叫**垂足**
- 垂直是相交的特殊情况

> 💡 想想十字路口：两条路交叉成 90° 角，就是互相垂直。

## 画平行线

用直尺和三角板画平行线：

1. 固定三角板，沿一条边画一条直线
2. 用直尺紧靠三角板的另一条边
3. 三角板沿直尺平移到新位置
4. 沿同一条边画第二条直线
5. 这两条直线就是平行的

## 画垂线

用三角板画垂线：

1. 把三角板的直角边对准已知直线
2. 沿另一条直角边画线
3. 这条线就和已知直线垂直

### 点到直线的距离

从直线外一点到这条直线，可以画很多条线段，但**垂直线段最短**。

这条最短的垂直线段的长度，就是**点到直线的距离**。

> 💡 记住：点到直线的距离 = 垂直线段的长度（最短的）。

## 生活中的平行与垂直

- **平行**：铁轨、斑马线、作业本的横线、楼梯扶手
- **垂直**：墙角的两条边、十字路口、桌面的边和桌腿

## 平行和垂直的关系

- 平行：永不相交
- 相交：有一个交点
- 垂直：相交且成 90°（是相交的特殊情况）

```
  平行        相交（一般）     垂直（相交特例）
  ─── ───      \  /              | 
                \/               |──
                /\               |
               /  \              |
```

## 注意事项

- 平行和垂直都是在**同一平面内**讨论的。
- 平行线永不相交，距离处处相等。
- 垂直是相交的特殊情况，夹角必须是 90°。
- 点到直线的距离，是垂直线段的长度（最短的）。
- 画平行线用"平移法"，画垂线用三角板的直角。
