# 圆的周长

## 什么是圆的周长？

围成圆的曲线的长度，就是圆的**周长**（C）。

怎么量呢？可以用**滚动法**——把圆在直尺上滚一圈，滚过的距离就是周长。

## 圆周率 π

不管圆多大，**周长 ÷ 直径** 的结果总是一个固定的数，大约是 **3.14159...**

这个数叫**圆周率**，用希腊字母 **π**（读 pài）表示。

> ### π ≈ 3.14

π 是一个**无限不循环小数**，平时计算取 3.14。

## 周长公式

因为 C ÷ d = π，所以：

> ### C = π × d
>
> - **C** = 周长
> - **d** = 直径
> - **π** ≈ 3.14

又因为直径 = 2 × 半径（d = 2r），所以：

> ### C = 2πr
>
> - **r** = 半径

## 算一算

**例 1：** 直径是 10 厘米，周长是多少？

- C = πd = 3.14 × 10 = **31.4 厘米**

**例 2：** 半径是 5 厘米，周长是多少？

- C = 2πr = 2 × 3.14 × 5 = **31.4 厘米**

**例 3：** 周长是 62.8 厘米，直径是多少？

- d = C ÷ π = 62.8 ÷ 3.14 = **20 厘米**

## 注意事项

- π 是一个**无限不循环小数**，不是 3.14，3.14 只是近似值
- 周长和直径的**比值**永远等于 π，不管圆多大
- 计算时 π 通常取 **3.14**
- 已知半径用 C = 2πr，已知直径用 C = πd
