# 小数的性质

## 小数的基本性质

你有没有想过，0.3 和 0.30 是不是一样大？

答案是：**一样大！**

> ### 小数的末尾添上 0 或去掉 0，小数的大小不变。

这就是**小数的基本性质**。

**例子：**

- 0.3 = 0.30 = 0.300
- 1.5 = 1.50 = 1.500
- 2.75 = 2.750

> 💡 为什么？0.3 是 3 个 0.1，0.30 是 30 个 0.01。10 个 0.01 = 1 个 0.1，所以 30 个 0.01 = 3 个 0.1 = 0.3。

## 化简小数

根据小数的性质，我们可以去掉小数末尾的 0，让小数更简洁。

**例 1：** 化简 0.70

- 0.70 = **0.7**（去掉末尾的 0）

**例 2：** 化简 105.0900

- 105.0900 = **105.09**（去掉末尾的 0）

> ⚠️ 注意：只能去掉**末尾**的 0，不能去掉中间的 0！
> - 0.50 → 0.5 ✓（末尾的0可以去掉）
> - 0.05 → 0.05 ✗（中间的0不能去掉，0.05 ≠ 0.5）
> - 0.505 → 0.505 ✗（中间的0不能去掉）

## 改写小数

有时候需要把小数改写成指定的小数位数，方法是**在末尾添 0**。

**例 3：** 把 0.3 改写成两位小数

- 0.3 = **0.30**

**例 4：** 把 4 改写成三位小数

- 4 = **4.000**

**例 5：** 把 2.5 改写成三位小数

- 2.5 = **2.500**

> 💡 改写不改变小数的大小，只是改变了表示形式。

## 小数大小的比较

比较两个小数的大小：

1. 先比**整数部分**——整数部分大的小数就大
2. 整数部分相同，比**十分位**——十分位大的小数就大
3. 十分位相同，比**百分位**——以此类推

**例 6：** 比较 3.56 和 3.65

- 整数部分：3 = 3
- 十分位：5 < 6
- 所以 **3.56 < 3.65**

**例 7：** 比较 0.3 和 0.299

- 整数部分：0 = 0
- 十分位：3 > 2
- 所以 **0.3 > 0.299**

> ⚠️ 比较小数时，不要看位数多少！0.3 虽然只有一位小数，但比 0.299（三位小数）大。

**例 8：** 比较 0.4 和 0.40

- 根据小数的性质，0.4 = 0.40
- 所以 **0.4 = 0.40**

## 生活中的应用

- 商品价格：3.50 元 = 3.5 元（化简）
- 比赛成绩：比较谁的用时短，12.8 秒 < 12.85 秒
- 身高比较：1.45 米 < 1.5 米（十分位 4 < 5）

## 注意事项

- 小数末尾添 0 或去 0，大小不变——这是小数的基本性质。
- 只能去掉**末尾**的 0，不能去掉中间的 0。
- 比较小数大小从高位到低位依次比较，和位数多少无关。
- 改写小数时，在末尾添 0 即可，不改变大小。
- 小数点不能随便移动！移动小数点会改变小数的大小。
