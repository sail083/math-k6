# 分数比较大小

## 分数也能比大小吗？

当然能！就像 3 比 2 大一样，分数也可以比较大小。不过分数比大小有两种情况，方法不一样。

## 情况一：分母相同（同分母分数）

**分母相同的分数，分子大的分数大。**

为什么？分母一样，说明每一份的大小一样。分子大的取的份数多，当然就大啦！

**例 1：** 比较 3/5 和 2/5 的大小

- 分母都是 5，每一份一样大
- 3/5 取了 3 份，2/5 取了 2 份
- 3 份 > 2 份
- 所以 **3/5 > 2/5**

想象一下：把同一个饼平均分成 5 份，吃 3 份肯定比吃 2 份多。

**例 2：** 比较 1/4 和 3/4

- 分母都是 4
- 1 < 3
- 所以 **1/4 < 3/4**

> 💡 同分母比大小，只看分子就行了！

## 情况二：分子相同（同分子分数）

**分子相同的分数，分母小的分数大。**

为什么？分子一样，说明取的份数一样多。分母小的说明每一份更大（因为分的份数少），所以取同样份数时，分母小的分数更大。

**例 3：** 比较 1/3 和 1/5 的大小

- 分子都是 1，都是取 1 份
- 分母 3 < 5，说明分成 3 份时每份更大
- 所以 **1/3 > 1/5**

想象一下：
- 把一个饼分成 3 份，每份比较大 → 1/3
- 把一个饼分成 5 份，每份比较小 → 1/5
- 同样取 1 份，当然是分成 3 份的那块更大！

**例 4：** 比较 1/2 和 1/4

- 分子都是 1
- 分母 2 < 4
- 所以 **1/2 > 1/4**

> 💡 同分子比大小，分母越小分数越大！

## 用图形来理解

画图比较最直观：

### 同分母比较

```
3/5:  ■■■□□   （5份中取3份）
2/5:  ■■□□□   （5份中取2份）
     3/5 > 2/5  ✓
```

### 同分子比较

```
1/3:  ■□□      （3份中取1份，每份大）
1/5:  ■□□□□    （5份中取1份，每份小）
     1/3 > 1/5  ✓
```

## 口诀总结

记住这两句话：

> - **同分母**分数比大小：**分子大**的分数大
> - **同分子**分数比大小：**分母小**的分数大

## 练一练

**例 5：** 在 ○ 里填 > 或 <

1. 2/7 ○ 5/7 → 同分母，2 < 5，所以 2/7 **<** 5/7
2. 1/6 ○ 1/4 → 同分子，6 > 4，所以 1/6 **<** 1/4
3. 4/9 ○ 4/9 → 一样大，所以 4/9 **=** 4/9

## 生活中的分数比较

- 你吃了蛋糕的 1/3，小明吃了 1/2，谁吃得多？→ 1/3 < 1/2，小明吃得多
- 一杯水喝了 3/5，另一杯喝了 2/5，哪杯喝得多？→ 3/5 > 2/5，第一杯喝得多

## 注意事项

- 同分母分数比分子，分子大的大。
- 同分子分数比分母，分母小的大（注意是反过来的！）。
- 如果分母和分子都不一样，可以用画图的方法比较（以后会学通分的方法）。
- 画图是最直观的方法，不确定的时候画画图。
