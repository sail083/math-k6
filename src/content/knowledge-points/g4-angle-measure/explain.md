# 角的度量

## 什么是角？

**角**是由一个**顶点**和两条**射线**组成的图形。

```
        一条边
         /
        /
  顶点 ●
        \
         \ 另一条边
```

- **顶点**：两条射线相交的点
- **边**：从顶点出发的两条射线

> 💡 角的大小跟两条边张开的程度有关，边张得越开，角越大。角的大小和边的长短没关系！

## 角的单位：度

量角用什么单位呢？用**度**，符号是 **°**。

把一个圆平均分成 360 份，每 1 份就是 **1 度**，写作 **1°**。

- 一个完整的圆 = 360°
- 半个圆 = 180°

## 认识量角器

**量角器**是量角的工具，形状是半圆形：

- 中心点：量角器正中间的点，要对准角的顶点
- 0° 刻度线：从中心点出发的基准线
- 内圈和外圈刻度：两圈数字，一圈从左到右 0→180，另一圈从右到左 0→180

> ⚠️ 量角器有两圈刻度，用哪圈取决于角的开口方向。

## 怎么量角？

量角三步走：

1. **中心对顶点**——量角器的中心点对准角的顶点
2. **0°线对一边**——量角器的 0° 刻度线对准角的一条边
3. **读另一边**——看角的另一条边对准哪个刻度，就是几度

> 💡 判断用哪圈刻度：0° 刻度线对准的那条边所在的半圈，就是你要读的刻度。

**例 1：** 量一个角

1. 中心点对准顶点
2. 0° 线对准下面那条边
3. 上面那条边对准刻度 60
4. 这个角是 **60°**

## 角的分类

根据角度大小，角分为几类：

| 名称 | 角度范围 | 特点 |
|---|---|---|
| 锐角 | 小于 90° | 比直角小 |
| 直角 | 等于 90° | 正正好好是 90° |
| 钝角 | 大于 90° 且小于 180° | 比直角大，比平角小 |
| 平角 | 等于 180° | 两条边在一条直线上 |
| 周角 | 等于 360° | 两条边重合，转一圈 |

```
锐角      直角      钝角       平角        周角
  /        |        \         ——         ●（转一圈）
 /         |         \
●          ●          ●
```

它们的大小关系：

> **锐角 < 直角 < 钝角 < 平角 < 周角**
>
> 1 周角 = 2 平角 = 4 直角

## 怎么画角？

画指定度数的角（比如画 65° 的角）：

1. 先画一条射线（作为一条边）
2. 射线的端点对准量角器中心点，射线对准 0° 刻度线
3. 在量角器上找到 65° 的位置，点一个点
4. 拿走量角器，从顶点出发，通过刚才的点画另一条射线
5. 标上 65°

## 生活中的角

- 钟表上 3 点整，时针和分针成 **90°**（直角）
- 钟表上 6 点整，时针和分针成 **180°**（平角）
- 三角板的角有 30°、45°、60°、90°
- 打开的书本形成的角是钝角

## 注意事项

- 角的大小看两条边张开的程度，和边的长短无关。
- 量角时中心点要对准顶点，0° 线要对准一条边。
- 读刻度时注意用对内圈还是外圈。
- 直角 = 90°，平角 = 180°，周角 = 360°。
- 1 周角 = 2 平角 = 4 直角。
