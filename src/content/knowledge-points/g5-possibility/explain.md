# 可能性

## 什么是可能性？

生活中有很多事情会发生，也有很多事情不会发生。我们用三个词来描述：

- **一定**：肯定会发生的事情
- **可能**：有可能发生，也有可能不发生
- **不可能**：绝对不会发生的事情

## 举个例子

**例子：** 盒子里有 3 个红球，1 个白球。

- 摸出红球 → **可能**（红球多，但不是一定能摸到）
- 摸出白球 → **可能**（白球少，但也有可能摸到）
- 摸出黑球 → **不可能**（盒子里没有黑球）

**例子：** 盒子里全是红球。

- 摸出红球 → **一定**（只有红球，一定能摸到）
- 摸出白球 → **不可能**（没有白球）

## 可能性有大小

可能性不是"有"或"没有"那么简单，它有**大小**之分。

- 红球 3 个，白球 1 个 → 摸出红球的可能性**大**，摸出白球的可能性**小**
- 红球 2 个，白球 2 个 → 摸出红球和白球的可能性**一样大**

> 💡 当球除颜色外完全相同、充分混合并随机摸取时，某种颜色所占数量越多，被摸到的可能性越大。

## 可能性的判断

| 情况 | 可能性 |
|------|--------|
| 全是红球，摸到红球 | 一定 |
| 全是红球，摸到白球 | 不可能 |
| 有红有白，摸到红球 | 可能 |
| 红球比白球多，摸到红球 | 可能性大 |
| 红球比白球少，摸到红球 | 可能性小 |

## 注意事项

- "一定"和"不可能"是确定的，"可能"是不确定的
- 可能性大小可以通过比较数量来判断
- 让可能性相等：让两种球的数量**一样多**
