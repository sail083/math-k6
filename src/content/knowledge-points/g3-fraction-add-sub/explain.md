# 同分母分数加减法

## 什么是同分母分数？

分母相同的分数叫**同分母分数**。

比如 1/5 和 2/5，分母都是 5，它们就是同分母分数。

## 同分母分数加法

### 先看一个例子

妈妈把一个蛋糕平均分成 5 份，你吃了 1 份（1/5），爸爸吃了 2 份（2/5），你和爸爸一共吃了这个蛋糕的几分之几？

用加法：**1/5 + 2/5 = ？**

### 用图形来理解

```
1/5:  ■□□□□   （5份中取1份）
2/5:  ■■□□□   （5份中取2份）
合起来: ■■■□□   （5份中取3份）
```

1 份 + 2 份 = 3 份，还是分成 5 份，所以结果是 **3/5**。

### 计算方法

> **分母不变，分子相加**

1/5 + 2/5 = (1+2)/5 = **3/5**

为什么分母不变？因为分母表示"分成几份"，两个人吃的是同一个蛋糕（分成5份），分的份数没变，只是吃的份数加起来了。

## 同分母分数减法

### 例子

一个蛋糕平均分成 5 份，吃了 4 份（4/5），还剩几分之几？

用减法：**5/5 - 4/5 = ？（整个蛋糕是5/5，减去吃掉的4/5）**

或者：**5/5 - 4/5 = ？（整个蛋糕减去吃掉的）**

### 用图形来理解

```
5/5:  ■■■■■   （5份全有）
4/5:  ■■■■□   （吃了4份）
剩:   □□□□■   （剩1份）
```

5/5 - 4/5 = (5-4)/5 = **1/5**

### 计算方法

> **分母不变，分子相减**

4/5 - 1/5 = (4-1)/5 = **3/5**

## 公式总结

同分母分数加减法的公式：

> ### 加法：a/c + b/c = (a+b)/c
> ### 减法：a/c - b/c = (a-b)/c

**分母不变，分子加减。**

## 算一算

**例 1：** 2/7 + 3/7 = ？

- 分母不变：还是 7
- 分子相加：2 + 3 = 5
- 结果：**5/7**

**例 2：** 5/8 - 2/8 = ？

- 分母不变：还是 8
- 分子相减：5 - 2 = 3
- 结果：**3/8**

**例 3：** 1/6 + 4/6 = ?

- 分母不变：6
- 分子相加：1 + 4 = 5
- 结果：**5/6**

## 几个特殊情况

- **1/3 + 2/3 = 3/3 = 1** → 分子等于分母时，就是整体 1
- **3/4 - 3/4 = 0/4 = 0** → 结果为 0
- **1 = 5/5 = 10/10** → 整体 1 可以写成分子分母相同的分数

## 注意事项

- 同分母分数加减法：**分母不变，只把分子加减**。
- 分母相同说明每一份的大小一样，才能直接加减。
- 结果如果能约分要约分（以后会学）。
- 分子等于分母时，结果就是 1（如 3/3 = 1）。
