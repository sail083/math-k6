# 分数加减法

## 同分母分数加减法

分母相同的分数，加减很简单：**分母不变，分子相加减**。

> ### 同分母加法：a/c + b/c = (a+b)/c
> ### 同分母减法：a/c − b/c = (a−b)/c

**例 1：** 1/5 + 2/5 = (1+2)/5 = **3/5**

**例 2：** 4/7 − 1/7 = (4−1)/7 = **3/7**

> 💡 就像同样的盘子大小，直接数有几个"块"就行。

## 异分母分数加减法

分母不同怎么办？**每一块的大小不一样**，不能直接加减！

### 关键步骤：先通分！

把不同分母的分数化成**同分母**的分数（用通分），然后按同分母的方法加减。

**例 3：** 1/2 + 1/3 = ？

1. **找公分母**：2 和 3 的最小公倍数是 6
2. **通分**：1/2 = 3/6，1/3 = 2/6
3. **相加**：3/6 + 2/6 = 5/6
4. **结果**：**5/6**

**例 4：** 2/3 − 1/4 = ？

1. **找公分母**：3 和 4 的最小公倍数是 12
2. **通分**：2/3 = 8/12，1/4 = 3/12
3. **相减**：8/12 − 3/12 = 5/12
4. **结果**：**5/12**

## 方法总结

1. 看分母是否相同
2. 不同就**通分**（找最小公倍数做公分母）
3. 分母不变，**分子加减**
4. 结果要化成**最简分数**

## 算一算

**例 5：** 1/4 + 1/6 = ？

- 公分母 = 12
- 1/4 = 3/12，1/6 = 2/12
- 3/12 + 2/12 = **5/12**

**例 6：** 5/6 − 1/3 = ？

- 公分母 = 6
- 1/3 = 2/6
- 5/6 − 2/6 = 3/6 = **1/2**（约分）

## 注意事项

- 结果一定要**约分**成最简分数
- 通分时用**最小公倍数**做公分母最简便
- 分母不同时，绝对不能直接把分子和分母分别相加！
