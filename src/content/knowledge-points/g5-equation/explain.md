# 简易方程

## 什么是方程？

含有**未知数**的**等式**，叫做方程。

- x + 3 = 7 ✅ 是方程（有未知数 x，也是等式）
- 3 + 4 = 7 ❌ 不是方程（没有未知数）
- x + 3 ❌ 不是方程（不是等式）

> 💡 记住：方程 = 等式 + 未知数，两个条件缺一不可。

## 等式的性质

方程是一种等式，解方程要用到**等式的性质**。

### 性质一：加减

等式两边**同时加上（或减去）**同一个数，等式仍然成立。

> 若 a = b，则 a + c = b + c，a − c = b − c

**想象天平：** 左边 = 右边时，两边同时加上或拿走同样重的东西，天平还是平衡的。

### 性质二：乘除

等式两边**同时乘（或除以）**同一个不为 0 的数，等式仍然成立。

> 若 a = b，则 a × c = b × c，a ÷ c = b ÷ c（c ≠ 0）

## 解方程

"解方程"就是求出未知数的值是多少。

**例子：** 解方程 x + 3 = 7

- 两边同时减 3：x + 3 − 3 = 7 − 3
- x = **4**

**例子：** 解方程 2x = 10

- 两边同时除以 2：2x ÷ 2 = 10 ÷ 2
- x = **5**

**例子：** 解方程 x − 5 = 8

- 两边同时加 5：x − 5 + 5 = 8 + 5
- x = **13**

## 检验

解完方程后，可以把结果**代回去**检验：

- x + 3 = 7，解得 x = 4
- 检验：4 + 3 = 7 ✅ 正确！

## 列方程解决问题

**例子：** 小明买了一些笔，每支 3 元，共花了 15 元。他买了几支笔？

1. 设未知数：设买了 x 支笔
2. 列方程：3x = 15
3. 解方程：x = 15 ÷ 3 = **5**
4. 答：他买了 5 支笔。

## 注意事项

- 解方程时每一步都要**保持等式成立**
- 乘除的时候，除数**不能为 0**
- 解完一定要**检验**，养成好习惯
