# AI 自主学习体验基线

## 产品结论

math-k6 不把自动播放、长篇讲解或单次高分视为学习完成。每门课采用同一条证据链：

`预测 → 两组对照实验 → 提交观察 → 证据解释 → 闭卷提取 → 新情境迁移 → 间隔复习`

AI 的职责是识别错误类型、选择下一种表征和安排复习；数学结论、答案和模型状态由受审课程内容与确定性程序控制。

## 三阶段职责

### 探索

- 操作前必须预测。
- 至少改变两次关键变量，形成可比较证据。
- 只有提交正确的不变量观察，才能进入发现。
- 点击一次控件不等于完成探索。

### 发现

- 不重复探索模型。
- 回放学习者的预测与实验次数，将证据连接到课程目标。
- 公式在证据之后出现。
- 必须完成一次隐藏模型的规律提取；错误时先提示证据冲突，不直接公布答案。

### 挑战

- 总正确率不低于 80%。
- 非选择式迁移题必须全部正确。
- 通过只表示“当堂迁移通过”，不冒充长期稳定掌握。

## 知识档案

- 默认使用单观点卡片播放器，支持前后翻页、页码、跳转、自动播放和暂停。
- 完整 Markdown 保留为参考模式，不承担主学习流程。
- 教材映射只在参考模式展示。

## 后续掌握模型

下一阶段应增加 `provisional`、`review_due`、`stable` 三种掌握状态，并记录首答、提示依赖、误区、作答耗时和复习时间。24 小时与 7 天后的异题复测通过后，才能标记稳定掌握。

## 禁止退化

- 探索和发现复用同一个模型。
- 任意一次操作即可解锁。
- 先给公式，再让学习者“发现”。
- 答错立即显示完整答案，并允许原题记忆过关。
- 单次 80% 永久标记掌握。
- 让生成式模型临场编造数学规则或答案。
