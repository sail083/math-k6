## 学习科学依据及适用边界

1. IES/WWC《Assisting Students Struggling with Mathematics: Intervention in the Elementary Grades》（2021），建议 6，第 51–55 页：将计时作为熟练度训练的一种方式，用于已经学习并具备策略的内容，强调准确性、个人进步与纠错反馈。其 1–5 分钟描述的是短时活动，不能换算成本产品每题的秒数标准。该指南针对小学数学干预，并非中国各年级单题操作常模。
2. WCAG 2.2，2.2.1 Timing Adjustable：为内容设置的时限应提供关闭、调整或延长等符合条件的方式。本实现提供开始前及进行中的不限时选择，不能凭“挑战”名称假定 essential 例外。
3. WCAG 2.2，4.1.3 / ARIA22：状态应可由辅助技术得知；状态容器应在消息变化前存在，设置合适的 live/atomic 语义。仅有 DOM 自动化不等于真实屏幕阅读器体验验收。

## 年级、任务及操作差异

| 学段 | 任务与操作考虑 | 准入原则 / 候选方向 |
| --- | --- | --- |
| 一至二年级（项目尚未提供该年级数学课程） | 阅读、符号辨识与触控定位仍需更多支持；不能将未支持年级视为已验收 | 不扩展年级、不设默认硬时限；未来须独立验证 |
| 三年级 | 将已学乘法事实与多位数进位程序分开；记录读题、保留中间结果和定位选项的负担 | 当前 23×4 先不限时；如试验计时，单独采样三年级进位题，不能套用乘法口诀题的时间 |
| 四年级 | 位值、进退位、读图读表与多条件任务的负担不同 | 只有明确的已学单一子技能可候选计时；读图推理及策略选择保留不限时 |
| 五年级 | 小数、分数转换与多步计算可能增加工作记忆负担 | 不因年级升高自动缩短；按步骤、符号复杂度和任务熟悉度分层 |
| 六年级 | 比例、应用建模、论证与迁移通常依赖较长思考 | 深度推理不限时；已学基础子技能可独立研究熟练度，不能用其替代建模与迁移证据 |

每个年级继续按触控、鼠标、键盘、屏幕阅读器及需要额外支持的学习者分层；不把慢操作归为数学错误，不要求辅助技术组向普通触控组的速度靠拢。不在前端猜测残障或自动给儿童打标签。

## 时限候选方案（均未批准）

| 方案 | 候选算法 / 使用条件 | 当前处置 |
| --- | --- | --- |
| A：不限时 | 新概念、多步推理、未校准内容、操作支持需求未覆盖；优先评价方法、准确性、独立性 | 已作为当前待审题的保守运行行为 |
| B：分层 P90 | 在自愿、受控的校准中，按年级×步骤复杂度×操作方式采集“主动开始并显示题目 → 独立正确提交”的完整时长，取该层 P90 作为试验起点 | 仅方案；不是通过线，不得写入题库并自动批准 |
| C：分层 P95 | 同 B，但以 P95 起步，适合希望降低时间压力的初始可用性试验 | 仅方案；是否优于 B 须比较体验、正确率与后续迁移 |

P90/P95 是候选覆盖比例，不是文献给出的教学标准。完整时长已经包含读题、定位和操作，不能再机械叠加同一操作耗时。不能只统计快速或正确学生而忽略未完成者：保留未完成、答错、退出及异常样本，分别报告，避免幸存者偏差。样本不足、长尾不稳定或存在明显组间差异时，继续不限时。

原 15 秒与原缺省 30 秒只能作为历史产品参数；没有证据说明其适合当前年级。本轮未采集学生数据，也未启动在线实验。

题目级批准并不证明每名学生具备先备能力；本轮没有根据个体学习数据自动决定计时资格。当前无真实 approved 项，正式启用时还须验证“先学后练”的使用路径。

正式批准前，教学负责人需审查：题目是否已学、是否存在有效解题策略、基础正确性和独立性、分层时长分布及不确定性、限时与不限时的体验和准确性差异、是否影响 D1/D7 与迁移、退出及焦虑反馈、辅助技术路径。不得把候选分位数、自动化通过或一条模拟题通过视为批准。

## 已实现的工程规则

| 编号 | 规则 | 自动化证据 |
| --- | --- | --- |
| T1 | `timeLimit` 必须显式为正、安全整数秒；缺失、0、负值、非有限、分数、字符串均不启用计时；不再补 30 秒 | Safety / Content 参数化回归 |
| T2 | 只有 `goal=fluency`、`reviewStatus=approved` 且审查字段齐全的有效单选题才提供计时入口；推理、待审与无效配置使用不限时 | Content + Safety；真实题库没有 approved 项 |
| T3 | 学生主动开始之前不倒计时且不暴露题干与选项；选择开始或不限时后显示题目；计时包括读题与操作，开始前和进行中都可选择不限时 | Safety；选择组关联题干和键盘说明；练习时长不是标准化测验 |
| T4 | 使用单调时钟的截止时间，不按回调次数减秒。输入和计时回调核对同一截止时间；处理时刻 `<deadline` 接受，`>=deadline` 超时 | 999ms、1000ms、1001ms、回调前输入、取消计时竞争回归 |
| T5 | 同步结果锁在更新 React 状态或调用外部回调之前占位；组件和 GameRunner 双层防重；卸载清理计时与监听；内容改变重开尝试，普通重渲染不重置时限 | StrictMode、同批次输入、重复输入、重渲染、换题、重开、卸载回归 |
| T6 | `timeout` 与实际提交错误分开。超时不计入该次知识得分分子/分母、不调用 `recordSkillEvidence`，不产生知识错误动画；所有计时作答也只作练习表现，不进入知识得分与技能证据，初学/D1/D7 一致 | Scoring 集成回归；无正确迁移证据仍不能通过；全超时不通过 |
| T7 | 主动提交仍反馈正误；不限时作答按正确性计知识分，限时单选最多在不限时路径映射 procedural；计时表现和误标均不能制造 conceptual/transfer/retention 证据 | Content + Keyboard + Scoring；迁移门槛保持独立非选择题 |
| T8 | 作答前不公开答案或解析。正常提交后立即给结果及方法；超时先中性说明，点击“查看答案与解析”才公布，不再回写结果 | Safety；结果页“答题回顾”本身是主动查看答案入口 |
| T9 | 保持挂载的 `role=status`、`aria-live=polite`、`aria-atomic=true`；倒计时 `role=timer`、`aria-live=off`，不每秒抢读；限时题作答或超时后均不自动把焦点移到下一题 | Safety / Scoring / ResultAnnouncements；真实阅读器仍需人工核验 |
| T10 | 切后台/pagehide、时钟非有限/异常/回退、明显睡眠或长调度间隙时，取消速度判断并保留未泄露答案的不限时作答；不自动判错 | Safety；本轮工程保护采用 100ms 采样、2,000ms 异常间隔，后者不是教学阈值 |
| T11 | 快捷键忽略 Ctrl/Cmd/Alt 组合键、长按重复、输入法组合、可编辑输入和其他组件区域；答案按钮支持原生键盘操作 | Safety / KeyboardShortcutModifiers |

边界以浏览器处理输入的时刻为准，不宣称测得儿童实际决定答案的时刻。超过 2 秒的调度或时钟异常宁可不生成速度结论；本实现不用于防作弊或排名。没有改变认证、API、数据库、历史学习记录或持久化 schema。

## 内容准入门禁

实现：`src/lib/timedChallengeQuality.ts`；门禁：`src/test/timedChallengeContent.test.ts`。

1. 扫描 `src/content/**/*.json` 的全部嵌套对象，覆盖常规题、D1/D7、备用形式；新增位置也会被扫描。没有明确课程年级上下文的限时项直接失败，不能遗漏在技能题库中。
2. 校验题目 ID、题干、方法解析、有限非负分值；2–4 个非空且去空格后不重复的单选项；正确答案必须是唯一字符串且属于选项；禁止数组答案伪装成单选。
3. 校验显式时限、训练目标、审查状态和理由。approved 项还需审核者、真实 ISO 日期及可检查的校准材料引用；推理不得批准为硬限时，证据类型不得伪装成迁移等证据。
4. 将当前唯一 pending 项的路径、题集位置、ID、题干、选项、答案、解析、时限与分值锁定为存量例外；新增或改写未审限时项使测试失败。不得为绕过门禁扩大例外清单。正式批准当前题时，应在同一审查变更中移除 pending 基线并补真实审核记录。
5. 含限时项的正式课程/复习题集仍须有不限时非选择式迁移题。自动化对现有 `23×4` 的算术及进位解释做独立回归；不声称能自动验证未来任意自然语言题的数学、干扰项质量或解析教学质量。
6. `npm run test` 自动包含门禁；`npm run test:timed-quality` 为限时题专项入口。构建本身不代替测试，合并前需两者通过。

```json
    "goal": "fluency",
    "reviewStatus": "pending",
    "rationale": "明确任务步骤与尚未完成的校准依据"
  }
}
```

测试夹具中的 approved 信息均为合成数据，只用于验证代码分支，不是当前课程的教学批准。
