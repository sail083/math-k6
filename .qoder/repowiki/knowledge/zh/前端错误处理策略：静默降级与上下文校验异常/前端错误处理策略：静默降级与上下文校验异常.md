该仓库是一个基于 Vite + React + TypeScript 的小学数学教学单页应用，整体代码量较小且功能聚焦于内容展示与游戏交互。在错误处理方面，项目没有建立统一的错误类型、错误码或全局错误中间件，而是采用以下分散但一致的轻量策略：

1. **运行时异常抛出（Context 使用校验）**：在 `src/context/ProgressContext.tsx` 的 `useProgress` Hook 中，当组件未包裹在 `ProgressProvider` 内时直接 `throw new Error('useProgress must be used within ProgressProvider')`，通过抛错强制开发者正确使用 Context。

2. **静默降级（内容加载失败）**：在 `src/lib/content.ts` 的 `loadKnowledgePointDetail` 函数中，对动态导入的 explain.md、derivation.json、game.json 文件使用 `.catch(() => '')` 和 `.catch(() => undefined)` 进行静默捕获，加载失败时返回空字符串或未定义值，保证页面不因单个资源缺失而崩溃。

3. **本地存储容错（localStorage 读写保护）**：在 `src/lib/progress.ts` 中，`loadProgress` 和 `saveProgress` 均使用 try-catch 包裹 localStorage 操作，解析失败或写入被拒绝时分别回退到默认进度对象或仅记录 console.error，确保用户数据损坏不影响应用运行。

4. **无统一错误体系**：项目中不存在自定义 Error 子类、错误码枚举、全局错误边界或错误日志上报机制。所有错误处理都是就地防御式编程，遵循“尽可能不中断用户体验”的原则。

这种处理方式适合小型教育类前端应用，但缺乏可观测性和可调试性，不适合需要严格错误追踪的生产级系统。
