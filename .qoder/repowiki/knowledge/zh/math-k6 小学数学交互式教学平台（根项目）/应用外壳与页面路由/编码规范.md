- 页面组件统一放在 `src/pages/` 目录下，按功能命名（HomePage、GradePage、KnowledgePointPage、ProgressDashboard），并通过 `lazy()` 在 App 中按需加载。
- 跨组件共享的学习进度通过 `ProgressProvider` 包裹根组件，子组件统一使用 `useProgress()` hook 访问，而非直接读取 context。
- 路由参数通过 `react-router-dom` 的 `useParams<{ ... }>()` 获取并做类型断言（如 `Number(grade) as Grade`），无效参数时返回友好提示页面。
- UI 样式全部使用 Tailwind CSS 原子类组合，颜色通过 CSS 自定义属性 `--color-*` 集中定义并在多处复用。
- 组件内状态变化后自动持久化的模式：在 `useEffect` 中监听状态变化并调用 `saveProgress` 写入存储。
