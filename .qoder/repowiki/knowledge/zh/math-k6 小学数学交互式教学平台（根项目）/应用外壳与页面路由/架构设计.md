应用以 `src/main.tsx` 为入口，通过 `react-dom/client` 的 `createRoot` 挂载 `<App />`，并使用 `<StrictMode>` 包裹。
- `src/App.tsx` 使用 `react-router-dom` 的 `BrowserRouter` + `Routes`/`Route` 定义路由：`/` 首页、`/grade/:grade` 年级列表、`/kp/:id` 知识点详情，未匹配路径重定向到 `/`；所有页面组件通过 `lazy()` 动态导入并由外层 `<Suspense>` 提供加载占位。
- 路由被 `<ProgressProvider>`（来自 `@/context/ProgressContext`）和 `Layout` 组件共同包裹，形成 Provider → Layout → Routes → Pages 的层级。
- `src/context/ProgressContext.tsx` 基于 React Context + `useState`/`useEffect`/`useMemo`/`useCallback` 实现学习进度的全局状态管理，并通过 `loadProgress`/`saveProgress` 持久化到本地存储，暴露 `progress`、`markPassed`、`isPassed`、`isUnlocked`、`getStars` 等方法。
- `src/pages/` 下每个 `.tsx` 对应一个路由页面，均通过 `useProgress()` hook 读取进度，通过 `@/lib/content` 获取知识点数据，通过 `react-router-dom` 的 `Link`/`useParams` 完成导航。
- `src/index.css` 引入 Tailwind CSS (`@import "tailwindcss"`)，并定义了主题色变量、Markdown prose 样式、滚动条隐藏等全局样式。
