- 所有对外暴露的数据结构以 TypeScript interface/type 形式集中在 types.ts 中声明，其他文件仅 import type 引用。
- 异步加载统一使用 `import.meta.glob` 配合 `{ eager: true }` 或默认懒加载模式，并通过 `.catch(() => undefined | '')` 容错处理缺失资源。
- 进度相关操作采用纯函数风格（输入 progress 对象返回新对象），避免直接修改传入参数，保证不可变性。
- 从文件系统路径提取知识点 ID 时使用正则 `//knowledge-points\/([^/]+)\//` 统一解析，确保 id 来源一致。
