- 每个组件都定义一个 `{ question: Question; onAnswer: (selectedAnswer: string, isCorrect: boolean) => void }` 形式的 Props 接口，并通过默认导出暴露组件。
- CheckIcon / XIcon / InfoIcon 等 SVG 图标以同文件内的函数组件形式重复定义，而非集中到共享库。
- 答案判定统一支持 `question.correctAnswer` 为字符串或字符串数组两种格式，通过 Array.isArray 分支处理。
- 交互流程遵循「未回答 → 用户操作 → 设置 hasAnswered=true → 调用 onAnswer」的单向状态流转，提交后禁用所有输入。
- 反馈区域统一采用绿色/红色边框 + 圆形图标 + 蓝色解析框的结构，错误时额外展示正确答案提示。
- 列表项最小高度统一设为 min-h-[48px]，按钮使用 disabled:opacity-30 disabled:cursor-not-allowed 表示不可用状态。
