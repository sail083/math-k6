本模块由四个独立的 React 函数式组件构成：DragAssembleGame（步骤排序）、DragMatchGame（左右匹配）、TimedChallengeGame（限时单选）、TimelineGame（时间线排序）。每个组件均遵循相同契约：接收 `question: Question` 与 `onAnswer(selectedAnswer: string, isCorrect: boolean)` 两个 props，内部通过 useState/useMemo/useEffect 管理本地交互状态，不依赖外部状态管理或 Redux。组件之间相互独立、无共享逻辑，仅共同依赖 `@/lib/types` 中的 Question 类型定义。UI 全部使用 Tailwind CSS 类名进行样式编排，图标以内联 SVG 函数组件形式定义在每个文件顶部。
